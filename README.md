# Explore Egypt

**Explore Egypt** is a web-based application that showcases the beauty, history, and modern culture of Egypt. Designed for travelers, students, and history enthusiasts, it provides a user-friendly and visually rich experience to learn more about one of the world’s most ancient civilizations.

## Features

- **Home Page:** Welcome screen with current local weather and time in Cairo.
- **Ancient Egypt:** Detailed overview of Egypt’s historical background and culture.
- **Modern Egypt:** Insight into today’s Egypt, including its cities, economy, and population.
- **Interactive Map:** Embedded Google Map showing Egypt's location.
- **Largest Cities Section:** Information and population data about major Egyptian cities.
- **Live Weather Integration:** Real-time weather data for Cairo and forecasts for the week.
- **Subscription Form:** Placeholder for newsletter updates.
- **Social Media Icons:** Interactive buttons linking to common platforms.

## Technologies Used

- **HTML5**
- **CSS3**
- **JavaScript**
- **Adobe XD** (for wireframes and UI mockups)
